# freepack

Free takeaway paper bags funded by advertisers.

## Product concept

- Takeaways order standard paper bags by the box for £0.
- Each bag size is produced in shared runs; every takeaway receives the same design for that run.
- The printable bag surface is divided into 3 cm × 3 cm advertising units.
- Advertisers purchase rectangular blocks such as 1×1, 1×2, 1×3, 2×2, 2×3, etc.
- Each run has a live availability grid, artwork upload, preview, checkout and production status.
- Admin manages bag sizes, production runs, advertising inventory, artwork approvals and takeaway stock.

## Initial stack

- React
- TypeScript
- Vite
- Supabase (planned: auth, database, storage)
- Stripe (planned: advertiser checkout)
- Netlify (planned: hosting/deploy)
